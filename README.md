# Raspberry Pi Scripts and Documentation

This repository contains a collection of scripts and documentation for setting up and configuring a Raspberry Pi.

## Scripts

The `scripts` directory contains a collection of useful scripts for automating tasks on your Raspberry Pi.

- `creating-new-command.sh`: A script that explains how to create a new command in `/usr/local/bin`.
- `docker-install.sh`: A script to install Docker on Ubuntu.
- `dynu`: Instructions for setting up dynamic DNS with Dynu.
- `necessary-tools.sh`: A script to install `net-tools`.
- `upgradePI.sh`: A script to update and upgrade the Raspberry Pi.

## Documentation

The `docs` directory contains documentation for setting up and configuring your Raspberry Pi.

- `add_sound`: Instructions for setting up a USB audio device.
- `cron_job`: A cron job to update and upgrade the system daily.
- `install-pi-without-monitor`: Instructions for installing Ubuntu on a Raspberry Pi without a monitor.
- `install_minikube`: A detailed guide to install Minikube on a Raspberry Pi.
